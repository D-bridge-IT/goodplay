# GoodPlay – браузерный прототип

Кликабельный прототип платформы из проектной заявки: хаб с десятью логическими играми,
симуляция рекламы с наградой, симуляция покупок, счётчик прозрачности 50/50,
стена эффекта и профиль. Интерфейс на немецком и русском (переключатель DE/RU).

## Онлайн

Опубликован на GitHub Pages: https://d-bridge-it.github.io/goodplay/
(репозиторий D-bridge-IT/goodplay, ветка main, корень). Обновление: загрузить
изменённые файлы через github.com/D-bridge-IT/goodplay/upload/main[/css|/js|/js/games]
и поднять `?v=N` у подключаемых css/js в index.html, чтобы сбросить кэш.

## Запуск

Двойной клик по `start.bat` (поднимает локальный сервер на порту 8773 и открывает
браузер) или вручную:

```
python -m http.server 8773
```

и открыть http://localhost:8773. На широком экране приложение показывается в рамке
телефона, на узком занимает весь экран. Никаких сборок и зависимостей не нужно:
чистые HTML/CSS/JS, библиотека Motion подгружается с CDN только для анимаций
(без интернета всё работает, просто без них).

## Игры (версия 0.6, логика и головоломки)

Все игры — чистые HTML/CSS/JS без движка, общая оболочка `js/kit.js` + `css/games.css`
(шапка со статистикой, окно результата с «удвоить звёзды за рекламу», подсказки/отмена хода
через сохранённую подсказку или рекламу = пожертвование). Каждая игра — `js/games/<id>.js` + `css/g-<id>.css`,
регистрируется через `Games.register()` со своими `thumb()`, `art()` (топ) и `badges`.

| id | Игра | Суть | Партнёр |
|---|---|---|---|
| chess (топ) | Шахматы | полные правила, движок alpha-beta в Web Worker (3 уровня), 34 задачи на мат в 1–2 | p4 |
| sudoku (топ) | Судоку | генератор с единственным решением, 4 уровня по технике, заметки, задача дня | p3 |
| solitaire (топ) | Пасьянс «Косынка» | Klondike, по 1/по 3, перетаскивание, авто-завершение | p5 |

| g2048 | 2048 | 4×4/5×5/6×6, лесная тема | p1 |
| connect4 | Четыре в ряд | ИИ negamax + таблица транспозиций, режим на двоих | p3 |
| checkers | Шашки | русские правила (летающие дамки, турецкий удар), ИИ alpha-beta | p5 |

## Звук и музыка

Эффекты — записанные сэмплы Kenney (CC0) из паков Interface Sounds, Impact Sounds, Digital Audio,
сконвертированные в mp3 (`assets/sfx`). Карта событий в `BANK` в `js/audio.js`: каждое событие — набор
файлов (случайный выбор), громкость, диапазон случайной высоты и шаг высоты за комбо. Пока сэмпл не
загружен, играет короткий синтезированный заменитель. Музыка — треки Kevin MacLeod (CC BY 4.0, атрибуция
в профиле и в CREDITS.md): `TRACKS` сопоставляет тему с треком; кросс-фейд, приглушение во время рекламы,
пауза при сворачивании вкладки. Звук стартует после первого касания. Настройки: эффекты, музыка, громкость.

## Что симулируется

- Реклама: 5 секунд вместо 15–30; каждый просмотр = 1 ц нетто, 0,5 ц партнёру игры.
- Покупки: модалка «Google Play / App Store», комиссия 15 %, затем 50/50.
- Счётчик сообщества: база 12 480 € плюс рост 0,08 ц/с (сценарий 5 000 DAU).
- Партнёры с пометкой «(Beispiel)» вымышлены; суммы — демо.

## Добавить игру

Создать `js/games/<id>.js`, вызвать `Games.register({ id, icon, bg, partner,
name:{de,ru}, tagline:{de,ru}, mount(root, ctx) })`, подключить скрипт в
`index.html` перед `hub.js`. Для canvas-игры: `Gfx.mountCanvas(root, {title, hint, cta})`
даёт обёртку с оверлеем «тапни, чтобы начать», `Gfx.setup(cv, wrap, ratio)` — контекст с DPR,
`Gfx.loop(fn)` — цикл с dt; из `destroy()` вызывать возвращённый `stop()`. В `ctx` доступны `stars(n)`, `ad()`, `badge(id)`,
`toast`, `modal`, `sound`, `data` (сохраняемый объект игры) и `save()`.

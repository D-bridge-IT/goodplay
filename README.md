# GoodPlay – браузерный прототип

Кликабельный прототип платформы из проектной заявки: хаб с шестью мини-играми,
симуляция рекламы с наградой, симуляция покупок, счётчик прозрачности 50/50,
стена эффекта и профиль. Интерфейс на немецком и русском (переключатель DE/RU).

## Онлайн

Опубликован на GitHub Pages: https://d-bridge-it.github.io/goodplay/
(репозиторий D-bridge-IT/goodplay, ветка main, корень). Обновление: загрузить
изменённые файлы через github.com/D-bridge-IT/goodplay/upload/main[/css|/js|/js/games]
и поднять `?v=N` у подключаемых css/js в index.html, чтобы сбросить кэш.

## Запуск

Двойной клик по `start.bat` (поднимает локальный сервер на порту 8773 и открывает
браузер) или вручную:

```
python -m http.server 8773
```

и открыть http://localhost:8773. На широком экране приложение показывается в рамке
телефона, на узком занимает весь экран. Никаких сборок и зависимостей не нужно:
чистые HTML/CSS/JS, библиотека Motion подгружается с CDN только для анимаций
(без интернета всё работает, просто без них).

## Структура

| Путь | Что внутри |
|---|---|
| `index.html` | каркас: шапка, экран, нижние вкладки |
| `css/style.css` | стили, рамка телефона, стили игр |
| `js/i18n.js` | строки DE/RU, функции `t()`, `L()`, `setLang()` |
| `js/state.js` | сохранение в localStorage, экономика, партнёры, форматирование |
| `js/ui.js` | тосты, модалки, звук, симуляция рекламы, реестр игр |
| `js/art.js` | вся графика: SVG-сцены (мост, арка, лес), спрайты животных и зданий, персонажи, превью карточек |
| `js/fx.js` | эффекты: частицы (`FX.burst`, `FX.confetti`), всплывающие числа (`FX.float`), полёт к счётчику (`FX.fly`), анимированный счёт (`FX.countUp`), тряска/вспышка, ripple на кнопках |
| `js/hub.js` | экраны «Игры», «Эффект», «Магазин», «Профиль», оболочка игры, согласие |
| `js/games/*.js` | шесть игр, каждая регистрируется через `Games.register()` |

## Что симулируется

- Реклама: 5 секунд вместо 15–30; каждый просмотр = 1 ц нетто, 0,5 ц партнёру игры.
- Покупки: модалка «Google Play / App Store», комиссия 15 %, затем 50/50.
- Счётчик сообщества: база 12 480 € плюс рост 0,08 ц/с (сценарий 5 000 DAU).
- Партнёры с пометкой «(Beispiel)» вымышлены; суммы — демо.

## Добавить игру

Создать `js/games/<id>.js`, вызвать `Games.register({ id, icon, bg, partner,
name:{de,ru}, tagline:{de,ru}, mount(root, ctx) })`, подключить скрипт в
`index.html` перед `hub.js`. В `ctx` доступны `stars(n)`, `ad()`, `badge(id)`,
`toast`, `modal`, `sound`, `data` (сохраняемый объект игры) и `save()`.

# GoodPlay – браузерный прототип

Кликабельный прототип платформы из проектной заявки: хаб с шестью мини-играми,
симуляция рекламы с наградой, симуляция покупок, счётчик прозрачности 50/50,
стена эффекта и профиль. Интерфейс на немецком и русском (переключатель DE/RU).

## Онлайн

Опубликован на GitHub Pages: https://d-bridge-it.github.io/goodplay/
(репозиторий D-bridge-IT/goodplay, ветка main, корень). Обновление: загрузить
изменённые файлы через github.com/D-bridge-IT/goodplay/upload/main[/css|/js|/js/games]
и поднять `?v=N` у подключаемых css/js в index.html, чтобы сбросить кэш.

## Запуск

Двойной клик по `start.bat` (поднимает локальный сервер на порту 8773 и открывает
браузер) или вручную:

```
python -m http.server 8773
```

и открыть http://localhost:8773. На широком экране приложение показывается в рамке
телефона, на узком занимает весь экран. Никаких сборок и зависимостей не нужно:
чистые HTML/CSS/JS, библиотека Motion подгружается с CDN только для анимаций
(без интернета всё работает, просто без них).

## Структура

| Путь | Что внутри |
|---|---|
| `index.html` | каркас: шапка, экран, нижние вкладки |
| `css/style.css` | стили, рамка телефона, карточки, canvas-обёртки игр |
| `js/i18n.js` | строки DE/RU, функции `t()`, `L()`, `setLang()` |
| `js/state.js` | сохранение в localStorage, экономика, партнёры, форматирование |
| `js/ui.js` | тосты, модалки, симуляция рекламы, реестр игр |
| `js/audio.js` | звук без файлов: синтезированные эффекты (`Snd.sfx`) и музыка (`Snd.music`, 8 тем) |
| `js/art.js` | SVG-иллюстрации хаба: превью карточек, сцена Obby Rush, логотип, персонажи |
| `js/fx.js` | DOM-эффекты хаба: конфетти, всплывающие числа, полёт к счётчику, ripple |
| `js/gfx.js` | общий canvas-набор игр: 2.5D-блоки и изометрические кубы, блочный аватар, небо/холмы/деревья, частицы, всплывающий текст, игровой цикл |
| `js/hub.js` | экраны «Игры», «Эффект», «Магазин», «Профиль», оболочка игры, согласие |
| `js/games/*.js` | семь игр на Canvas 2D, каждая регистрируется через `Games.register()` |

## Игры

Все игры рисуются на Canvas 2D через `js/gfx.js` в едином «игрушечном» стиле: объёмные блоки,
блочный аватар, частицы, тряска камеры, баннеры, день/ночь. Управление одним пальцем.

| Игра | Жанр | Партнёр (демо) |
|---|---|---|
| **Obby Rush** (топ-игра) | авто-раннер-обби: тап = прыжок, 2× = двойной; killbricks, спиннеры, батуты, ускорители, лава; 3 жизни, чекпоинт каждые 10 платформ | Spielplatz-Initiative |
| Wortbrücke / Словарный мост | слова из букв-блоков, каждое слово = доска, 5 досок = аватар перебегает реку; 8 заданий | Lesestart Ruhrgebiet |
| Waldklicker / Лесной кликер | лесной тайкун: 12 участков, три стадии роста, встряхивание деревьев, яблоки, дождь ×2, олень за бонус, 4 апгрейда (лейка, пчёлы, спринклер, лесник) | Waldfreunde Ruhr |
| Pfoten in Reihe / Лапки в ряд | match-3 7×7 с перетаскиванием, полосатые фишки (4 в ряд), радужная косточка (5), каскады с комбо, уровни с растущей целью | Tierheim Dortmund-Nord |
| Doktor Quiz | квиз-забег по коридору клиники: 4 двери = 4 ответа, 15 с на вопрос, серия ×, джокер 50:50; 18 вопросов, 8 за раунд | Gesund im Quartier |
| Kleinstadt / Маленький город | изометрический градостроитель 7×7: дороги с машинками, дома, пекарни, парки, школы, доход всплывает над зданиями, день/ночь | Spielplatz-Initiative |
| Brückenbauer / Строитель моста | стек-башня: кран качает камень, тап = бросить, лишнее отламывается, идеальные попадания = комбо и расширение; каждые 12 камней = секция опоры | Sprachcafé · D-Bridge e.V. |

Внутри каждой игры есть отладочный хук на элементе canvas (`cv.__ob`, `__m3`, `__pb`, `__wk`,
`__qz`, `__ks`, `__wb`) для автопрогонов из консоли.

## Что симулируется

- Реклама: 5 секунд вместо 15–30; каждый просмотр = 1 ц нетто, 0,5 ц партнёру игры.
- Покупки: модалка «Google Play / App Store», комиссия 15 %, затем 50/50.
- Счётчик сообщества: база 12 480 € плюс рост 0,08 ц/с (сценарий 5 000 DAU).
- Партнёры с пометкой «(Beispiel)» вымышлены; суммы — демо.

## Добавить игру

Создать `js/games/<id>.js`, вызвать `Games.register({ id, icon, bg, partner,
name:{de,ru}, tagline:{de,ru}, mount(root, ctx) })`, подключить скрипт в
`index.html` перед `hub.js`. Для canvas-игры: `Gfx.mountCanvas(root, {title, hint, cta})`
даёт обёртку с оверлеем «тапни, чтобы начать», `Gfx.setup(cv, wrap, ratio)` — контекст с DPR,
`Gfx.loop(fn)` — цикл с dt; из `destroy()` вызывать возвращённый `stop()`. В `ctx` доступны `stars(n)`, `ad()`, `badge(id)`,
`toast`, `modal`, `sound`, `data` (сохраняемый объект игры) и `save()`.
